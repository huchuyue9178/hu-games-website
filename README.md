# Hu Games 官网

Hu Games 的官方网站，单文件构建，黑底 + 金色 + 薄荷绿的液态玻璃视觉，两款游戏可在站内直接试玩。

## 作品

| 作品 | 类型 | 状态 |
| --- | --- | --- |
| 偷吃乌龟 2026 | 休闲摸金 / 潜入开箱 | 已上线，可站内试玩 |
| 零点射击场 ZEROING RANGE | 室内战术射击 / 60 秒计时 | 已上线，可站内试玩 |

> 注意：官网内嵌的均为**试玩版**，不支持账号登录，进度存档、账号成长与云端数据无法同步；完整功能请在正式客户端体验。

## 特点

- **纯单文件**：`index.html` 包含全部样式、脚本、图片与两款游戏本体，断开网络也能完整运行
- **液态玻璃质感**：背景环境光标 + `backdrop-filter` 玻璃层，圆角胶囊按钮
- **SVG 开场动画**：Logo 轮廓矢量化后逐段描边，扫光填充，收尾淡出
- **站内试玩**：两款游戏以 `iframe srcdoc` 内嵌，弹窗内切换，无需跳转

## 本地运行

直接双击打开 `index.html`，或用任意静态服务器：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 说明

- 射击场使用 Three.js 渲染 3D 靶场，需要浏览器支持 WebGL
- 页面字体优先加载在线字体，离线时回退到系统字体，不影响功能
